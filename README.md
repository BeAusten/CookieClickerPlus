# CookieClickerPlus

**CookieClickerPlus** is a Cookie Clicker mod that aims to improve the gameplay experience with useful tools, enhancements and quality-of-life features.

## Features

**Note:** CookieClickerPlus does not modify Cookie Clicker's original game files or source code.

### Building Efficiency

- Compare buildings based on their Cookies Per Second (CPS) efficiency.
- Automatically calculate the value of each building.
- Highlight the most efficient building with a golden badge.
- Automatically update values as the game progresses.

## Installation

1. Download `cookie.js` from this repository.
2. Open [Cookie Clicker](https://orteil.dashnet.org/cookieclicker/).
3. Open the browser developer console (`F12`).
4. Open `cookie.js` with a text editor and copy its contents.
5. Paste the code into the console and press `Enter`.

The mod will now run in your game!

**Note:** You may need to repeat these steps whenever you restart the game.

**Security warning:** Only paste JavaScript code into your browser console if you understand and trust what it does.
